# 📡 Mobile Cell Tower Finder (`cell-tower-live`)

An interactive, responsive web application designed to map and identify nearby mobile cell towers relative to a user's real-time GPS location. Built with modern, zero-dependency HTML5, CSS3, JavaScript, and Leaflet.js.

---

## ✨ Features

- **📍 Real-Time GPS Tracking:** Automatically detects and displays your live location on an interactive map.
- **🗼 Cell Tower Mapping:** Visualizes nearby cell towers with status indicators (Connected vs. Muted/Idle towers).
- **🎨 Dark Mode UI:** Modern, futuristic dark theme (`#0a0e17`) with glowing neon indicators for visual clarity.
- **📱 Fully Responsive & PWA Ready:** Optimized for seamless performance on both mobile browsers and desktop devices with mobile status bar meta tags.
- **⚡ Lightweight & Fast:** Built using single-file architecture (`index.html`) using Leaflet.js for ultra-fast mapping without heavy frontend frameworks.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern CSS (Variables, Flexbox), Vanilla JavaScript (ES6+)
- **Mapping Engine:** [Leaflet.js](https://leafletjs.com/) (v1.9.4 via CDN)
- **Deployment:** GitHub Pages
